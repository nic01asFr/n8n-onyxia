### Piloter n8n depuis un assistant (MCP)

- Adresse MCP : `{{ $mcpUrl }}`
- Jeton : `{{ include "n8n.mcpToken" . }}`

Claude Code :

```bash
claude mcp add n8n --transport http {{ $mcpUrl }} --header "Authorization: Bearer {{ include "n8n.mcpToken" . }}"
```

La clé API n8n du serveur MCP est créée automatiquement, avec des droits
limités aux workflows, exécutions, étiquettes, tables, credentials et dossiers.
{{- end }}
