### Mettre des workflows à disposition (portail d'actions)

Dans un document Grist, ajoutez un widget personnalisé avec l'adresse
ci-dessous et un accès complet au document :

```
https://{{ .Values.portal.hostname }}/
```

Pour choisir les workflows exposés : dans le widget, connecté à Grist,
cliquez sur « Configurer » et connectez-vous avec le compte n8n ci-dessus (ou
une clé API). Le premier compte Grist qui s'y connecte devient propriétaire du
portail.

Un workflow devient une action par son déclencheur Webhook : méthode POST,
workflow publié, authentification Header Auth avec le credential « Portail
d'actions (en-tête) », créé automatiquement dans n8n.
{{- end }}

### Share workflows as actions (action portal)

In a Grist document, add a custom widget with the address below and full
document access:

```
https://{{ .Values.portal.hostname }}/
```

To choose the exposed workflows: in the widget, signed in to Grist, click
"Configurer" and sign in with the n8n account above (or an API key). The first
Grist account to sign in there becomes the portal owner.

A workflow becomes an action through its Webhook trigger: POST, published, and
Header Auth with the "Portail d'actions (en-tête)" credential, created
automatically in n8n.
{{- end }}
